# Stomping Tantrum: bounded public previous-result contract

Pinned native Stomping Tantrum doubles base power only when `moveLastTurnResult === false`. Native `true`, `null` and `undefined` do not double it. Ordinary Protect blocking returns a non-failure `null`; a move missing, hitting an ordinary immunity, or being prevented by flinch can be an actual `false`. Native endTurn transfers `moveThisTurnResult`, then clears it. Switching clears both fields.

The repair admits an active holder only when complete, ordered public history supplies an explicit certificate for its previous result. A directly damaging action or successful public Protect/Follow Me supplies a success witness; explicit failure/miss/immunity supplies a failure witness; ordinary Protect blocking without another successful or failing spread target supplies `null`. At least one successful spread target takes precedence over a failed or protected target. A fresh switch or complete turn without an action supplies the native absence result. Called/multiple actions, missing outcome evidence, confusion prevention, incomplete history and unsupported mechanics remain closed. No result is inferred merely because the Pokémon dealt no damage.

The first supported scope is an ordinary move request. A publicly observed post-upkeep replacement may reset the incoming holder before that request. A replacement request itself remains unsupported for active holders because its separate current-turn result needs another contract. Inactive holders retain their existing native switch-reset certificate.

Reconstruction uses native `useMove` witnesses and native `endTurn` to establish the *already publicly certified* result. Splash supplies success, Steel Roller without terrain supplies failure, and a protected Water Gun supplies `null`. These are inert setter witnesses, not assertions that those moves occurred historically. They do not add to public action counts or deduct PP. No serialized result, arbitrary history, convenient default or guessed failure flag is patched into a candidate. Exact active tenure, PP, effects, inventory, projection, legal menu, previous result and absence of a current-turn result are independently checked afterward.

A read-only audit first classified public histories from the sealed Mega suite, then compared each certificate with the actual native field. **833 certified fields matched, with zero discrepancies:** 410 true, 353 undefined, 65 false and five null. Unresolved fields were not counted as matches. This is internal verification on development data, not gameplay evidence. The audit reads native truth only after classifying public inputs, and no truth is passed to admission or the player.

Controls cover ordinary success, immunity failure, Protect block, partial spread success, switching, flinch and a Mega holder, including exact public projection and legal-menu equivalence. Corrupting the hidden result while retaining identical public projection is rejected. Missing ledger, missing outcome, repeated action, confusion, missing upkeep and replacement phase remain rejected. A native damage control verifies larger damage after failure and equal normal damage after success versus Protect blocking.

Validation: **111 targeted tests passed**, including the existing speed, Charcoal, weather, persistent lifecycle, public rebase, experimental player and three retained continuation regressions. Native worker syntax, changed Python lint checks and whitespace checks passed. No strategic weight, prior catalogue, candidate limit or response limit changed.

Sources: `src/champions_practice/public_move_result.py`, `tests/test_stomping_admission.py`; read-only reproduction: `PYTHONPATH=src python scripts/stomping_public_result_audit.py` with the ignored original Mega archive available. Paired gameplay is a separately frozen regression experiment.
