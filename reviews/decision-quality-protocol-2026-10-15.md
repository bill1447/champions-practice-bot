# Decision quality: frozen protocol

Freeze this protocol before evaluating the new tie selector. Admission, utility
weights, hypotheses, horizon, 8/3 coverage and decision budget remain unchanged.
Only the final root ordering of exactly equal worst-world and weighted-world
scores changes. Within each such tie, remove pointwise-dominated candidates
before proposal order; retain stable ordering within nondominated frontiers.
Dominance requires identical world identities, weights and response coverage.
It is a statement about sampled response means, not all possible counterplay.
Continuation and replacement selection remain unchanged.

Development set: the four retained preservation/conversion cases from the
frozen-v4 diagnostic. Regression expectation: repair the repeated-Protect
dominated tie; preserve the other three root choices. Do not label all Protect
choices errors. The lone Venusaur case has a native Sleep Powder opportunity
that a frozen V2 continuation fails to exploit.

Separate archival audit: every completed native root ranking in inventory-v1,
excluding the four development checkpoints. Freeze twelve inspection cases by
sorting SHA256(game-id + ':' + checkpoint), without considering scores or game
outcomes. Audit all remaining rankings too. These are held-out *checkpoints*,
not unseen teams or independent strength evidence; the source games have
already informed development. Category flags derive only from legal commands:
offense, shielding, switching, speed control. KO/trade labels require native
consequences; a legal attacking command alone cannot establish an opportunity.

Gates: preserve every candidate's utility and branch evidence; never change a
strict robust-score preference; never choose a sampled-dominated action from
the top tied group; do not force an incomparable shield/offense preference.
Record choices, disagreements and sampled dominators, including zero changes.
Use generated matrix tests for semantics; the archival audit tests transfer.

Route/opportunity comparison remains diagnostic, using the existing coupled
eight-RNG continuation samples: report terminal wins/losses, threats remaining,
living allies, and actually executed damaging actions, including each actor.
Compare choices with existing utility ranks without fitting coefficients.
Report first-turn and second-turn outcomes separately. Frozen V2 continuation
and the small opponent response family limit conclusions; existing native
next-turn witnesses are evidence of possible tactics, not certified win routes.
No candidate plan gets a new bonus or a designated immutable finisher.

If the gates pass, rerun the same 24 paired full-game cases against frozen V2
as a regression experiment. Compare native trajectories with inventory-v1.
This is not an independent replication of the earlier 15/24 versus 10/24 result.
Stronger opponents with validated Mega behavior and fresh compositions remain
required before claiming broader competence or promoting the player.
